# Student Task manager

## 1. Introduction
Student Task manager is a web application designed to help students organize and manage their daily academic tasks.

## 2. Objective 
- Organize academic tasks.
- Track Completed and pending tasks.
- Improve task management.
- Provide a simpler user interface.
- Provide a simple user interface.

## 3. Technologies used
- HTML5
- CSS3
- JavaScript
- Local Storage
- GitHub Pages

  ## 4. Features
  - Add new tasks.
  - Edit existing tasks.
  - Mark tasks as completed.
  - Delete tasks.
  - Search for tasks.
  - Filter tasks by status.
  - dashboard with task satistics.
  - Progress bar.
  - Save tasks using browser Local storage.
  - Light Mode and Dark Mode.
  - Due dates for tasks.
  - Responsive layouts for different screen sizes.

    ## 5. Working of the Project
    Users can add tasks and optionally assign due dates. Ther can edit, complete, search, filter, and delete tasks. The dashboard displays task statistics, while the progress bar shows completion progress. Local Storage save tasks in the browser.

    ## 6. Advantages
    - Easy to use.
    - Helps students organize their work.
    - Displays task progress.
    - Work in a modern web browser.

    ## 7. Limitations
    - Tasks are stored in the browser's Local Storage.
    - Tasks do not automatically synchronize between devices.
    - Clearing browser site data may remove saved tasks.

     ## 8. Future Enhancements
    - User login and registration.
    - Deadline notifications.
    - Cloud storage.
    - Synchronization across devices.
   
      ## 9. Conclusion
      Student Task Manager demonstrates how HTML, CSS, and JavaScript can be used to create a useful task management application for students.
